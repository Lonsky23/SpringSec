## Spring Security JWT Practice ##

This is my first practice project using **Spring Security with JWT (JSON Web Tokens)**. 

IMPLEMENTED FEATURES 

- ✅ User Registration  
- ✅ User Authentication  
- ✅ JWT Token-based Security

TUTORIAL

This project is guided by a tutorial from **Amigoscode**.  
Check out their amazing content on Spring Boot and backend development!

TECHNOLOGIES USED 

- Java
- Spring Boot
- Spring Security
- JWT (JSON Web Token)
- Maven

PURPOSE

To learn and apply Spring Security with JWT for stateless authentication in REST APIs.
